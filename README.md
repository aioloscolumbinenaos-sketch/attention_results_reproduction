### Attention is all you need implementation 

In this repo, I am implementing the attention is all you need paper and trying to reproduce some of its results.

For now, the scope of the project is to compare the different layer types in terms of complexity by emprirically validating the scaling behavior of each layer type. In other words, we try to reproduce table 1 of the Attention is all you need paper.

First we implement the different layer types. Second, we define a training and evaluation protocol to study complexity behavior of each layer type. Third we obtain results for the emperical study and check it against the table 1 results from the paper.
